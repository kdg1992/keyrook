# PuTTY PPK interoperability fixtures

These four synthetic Ed25519 keys are verbatim test vectors from PuTTY 0.85,
`test/cryptsuite.py`, `testPPKLoadSave`. They are public test data, never deployment keys.
The test passphrase is `test-passphrase`.
